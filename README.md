# Курсовая работа по реализации бэкенда банковского приложения

## Описание:
### Написана функция main включающая в себя обработку excel выдачу информации по тратам по картам, топ 5 транзакций курс валют и акций.
Проект виджетов банковских операций клиента - это проект/курсовая по серверной части виджетов банковских операций клиента.
На данный момент реализованны следующие функции:  
- **decorator_log** Декоратор для отслеживания и записи результатов функции 
- **currency_conversion** Запрос курса валюты в рублях API 
- **stock_prices** Запрос курса акций API 
- **excel_file_reader** Функция принимает путь к файлу exel и выдаёт df 
- **spending_by_category** Функция возвращает траты по заданной категории за последние три месяца (от переданной даты).
- **category_cashback** Принимает датафрейм и фильтрует по категориям кэшбека
- **get_greeting** Принимает актуальное время и выдаёт приветствие
- **get_cards** Принемает датафрем фильтрует по дате и списанию затем выдаёт словарь с суммой расходов, кэшбэком по картам
- **get_top_transactions** Принемает датафрем фильтрует по дате и списанию затем выдаёт словарь с топ 5 расходов, кэшбэком по картам
- **get_currency_conversion** Удобно формирует ответ по курсу валюте
- **get_stock_prices** Удобно формирует курсы указанных акций
